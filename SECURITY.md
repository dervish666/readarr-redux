# Security Policy

## Reporting a vulnerability

Report it privately through GitHub: on this repository, open the Security tab and choose "Report a vulnerability" (https://github.com/dervish666/readarr-redux/security/advisories/new). Please don't open a public issue or post it in Discussions.

One person maintains this fork in his spare time. Expect a first reply within a week. A confirmed issue gets a fix and a new image as soon as its severity warrants, and the advisory is published once the fixed image is out.

If the problem is also in Sonarr, Radarr, Lidarr or Prowlarr, which share much of this code, report it to the Servarr team as well, following their own security policy. They don't support Readarr Redux, so please don't send them issues that only affect this fork.

## Supported versions

Only the latest image (`ghcr.io/dervish666/readarr:latest`) and the head of `develop` get fixes.
